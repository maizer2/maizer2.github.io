# 3D Neural Field Generation using Triplane Diffusion

* 저자 : J. Ryan Shue, Eric Ryan Chan, Ryan Po, Zachary Ankner, Jiajun Wu, Gordon Wetzstein (Stanford)
* 학회 : CVPR 2023, [arXiv:2211.16677](https://arxiv.org/abs/2211.16677)
* 프로젝트 : [https://jryanshue.com/nfd/](https://jryanshue.com/nfd/)

![Figure-2](https://raw.githubusercontent.com/maizer2/gitblog_img/main/1.%20Computer%20Engineering/1.7.%20Literature%20Review/2023-06-23-(diffusion)NFD/Figure-2.PNG)

## 한 줄 요약

3D 형상(occupancy field)을 **세 장의 축 정렬된 2D feature plane(triplane)**으로 분해해 두면, 3D 생성 문제가 "다중 채널 2D 이미지 생성" 문제가 된다. 따라서 **기존 2D diffusion 모델(ADM U-Net)을 거의 그대로** 적용해 고품질·고다양성의 3D neural field를 생성할 수 있다는 것을 보인 논문이다. 핵심 기여는 triplane을 diffusion이 학습하기 쉽게 만드는 정규화·규격화 기법이다.

## Abstract

본 논문은 3D-aware generation of neural fields에 Diffusion 모델을 적용시킨다.

* 3D-aware generation은 생성 과정에서 3차원 정보를 고려하여 생성하는 방법이다.
* Neural fields는 좌표를 입력받아 값을 출력하는 신경망으로 표현된 공간적 데이터 구조를 의미한다. 여기서는 3D 좌표 → occupancy(안/밖)를 출력한다.

ShapeNet 메시를 연속적인 occupancy field로 변환하고, 이를 triplane feature로 분해한 뒤, 그 위에 2D diffusion을 학습한다. 기존 triplane 분해 파이프라인을 그대로 쓰면 diffusion이 학습하기 어려워, 몇 가지 필수적인 변경을 가했다고 밝힌다.

## 1. Introduction

3D-aware generative adversarial networks (GANs)의 생성 방법을 Diffusion model을 사용하여 성능을 개선시켰다.

3D-aware GANs(EG3D 등)는 2D generator를 사용하여 높은 성능의 3D shape 생성에 성공하였다.

본 논문은 3D-aware GANs의 아이디어를 발전시켜, 3D scenes과 radiance fields를 축에 정렬<sup>axis-aligned</sup>된 2D feature 평면의 집합으로 인코딩하는 "triplane representations"를 생성하는 것을 학습하는 것을 제안한다.

* Triplane은 3D 데이터를 표현하기 위해 세 개의 평면($xy$, $xz$, $yz$)으로 구성된 표현 방법을 의미하며 그림에서 확인할 수 있다.

본 논문에서 소개하는 Neural field-based diffusion framework for 3D representation learning은 두 단계로 진행된다.

1. 3D scenes 훈련 데이터셋은 장면별로 triplane features 세트와 단일 shared feature 디코더(MLP)로 분해된다.
2. 분해된 triplane에 대해 2D Diffusion 모델을 훈련한다.

훈련된 Diffusion 모델은 추론 시에 새롭고 다양한 3D 장면을 생성하는 데 사용될 수 있다.

Triplane을 다중 채널 2D 이미지로 해석하여 생성과 렌더링을 분리함으로써, 현재의 (그리고 미래의) state-of-the-art 2D Diffusion 모델 백본을 거의 그대로 활용할 수 있다.

## 3. Method

### 3.1 Triplane representation

* 3D 점 $p = (x, y, z)$에 대해 세 평면 $F_{xy}, F_{xz}, F_{yz} \in \mathbb{R}^{N\times N\times C}$에 각각 투영해 bilinear 보간으로 feature를 뽑고, 세 feature를 더한 뒤 작은 MLP 디코더에 넣어 occupancy를 얻는다.

$$ o(p) = \text{MLP}\big(F_{xy}(x,y) + F_{xz}(x,z) + F_{yz}(y,z)\big) $$

* 메모리가 voxel grid($O(N^3)$)보다 훨씬 적게 들고($O(3N^2)$), 평면이 2D 이미지와 같은 모양이라 2D 네트워크를 쓸 수 있다.

### 3.2 Stage 1 : 데이터셋을 triplane으로 분해

* ShapeNet 메시를 watertight로 만들고 점들을 샘플링해 occupancy 라벨을 얻는다.
* 모든 형상에 대해 **MLP 디코더는 하나로 공유**하고, 형상마다 자신의 triplane feature를 최적화한다. 디코더를 공유해야 triplane들이 같은 "언어"로 쓰여 diffusion이 분포를 학습할 수 있다.
* 두 단계로 진행한다. 먼저 일부 형상으로 디코더와 triplane을 함께 학습하고, 디코더를 고정한 뒤 나머지 형상의 triplane만 맞춘다.

### 3.3 Triplane을 diffusion에 맞게 만들기

이 부분이 논문의 실질적 기여다. 그대로 최적화한 triplane은 값 범위가 제멋대로이고 고주파 noise가 많아 diffusion이 학습하기 어렵다.

* **정규화 항** : triplane 최적화 시 **Total Variation(TV) 손실**로 평면을 공간적으로 매끄럽게 만들고, **L2 norm 손실**로 값 크기를 제한하며, 표면에서 먼 곳의 밀도를 억제하는 **explicit density regularization**을 추가한다. 이렇게 만든 triplane은 자연 이미지처럼 저주파 위주의 구조를 가진다.
* **값 범위 규격화** : triplane 값을 이미지처럼 고정 범위(예: $[-1, 1]$)로 정규화해 diffusion의 noise schedule과 맞춘다.
* **채널 결합** : 세 평면을 채널 방향으로 이어 붙여 $N \times N \times 3C$ 짜리 하나의 "이미지"로 다룬다.

### 3.4 Stage 2 : 2D diffusion 학습

* ADM(Dhariwal & Nichol) 계열 U-Net을 거의 수정 없이 사용해 triplane 이미지에 DDPM을 학습한다.
* 샘플링 후 생성된 triplane을 공유 디코더로 질의해 occupancy field를 만들고, marching cubes로 메시를 추출한다.

## 4. Experiments

* **데이터셋** : ShapeNet의 car, chair, airplane 클래스.
* **비교 대상** : point cloud diffusion(PVD), SDF 기반 GAN(SDF-StyleGAN), 3D-aware GAN 계열 등.
* **평가 지표** : 생성 형상을 여러 시점에서 렌더링한 이미지에 대한 FID, 그리고 분포 관점의 precision / recall(또는 coverage / MMD 계열) 지표.
* **결과**
    * 세 클래스 모두에서 비교 대상보다 낮은 FID와 높은 다양성을 보고하며, 특히 얇은 구조(의자 다리, 비행기 날개)에서 세부 묘사가 뚜렷하다.
    * **Ablation** : 정규화 없이 만든 triplane으로 학습하면 diffusion이 수렴하지 못하거나 품질이 크게 떨어진다. TV·L2·밀도 정규화가 모두 필요하다.
    * 2D diffusion의 장점을 그대로 이어받아 **보간, 조건부 생성(일부 평면 고정)** 같은 조작이 가능하다.

## 5. 정리 및 의의

* **기여** : "3D 표현을 2D 이미지처럼 만들면 2D 생성 모델을 재사용할 수 있다"는 설계. 핵심은 diffusion 자체가 아니라 **표현(triplane)을 생성 모델 친화적으로 규격화**한 데 있다.
* **의의** : 이후 triplane diffusion 기반의 3D 생성(Rodin, 3DGen 등)과 large reconstruction model 계열이 같은 표현을 쓴다. 표현 학습과 생성 학습을 분리하는 2단계 구조는 [Latent Diffusion](https://maizer2.github.io/1.%20computer%20engineering/2023/02/01/stable-diffusion.html)과 같은 철학이다.
* **한계** : 형상마다 triplane을 최적화해야 해 데이터셋 전처리 비용이 크고, 단일 클래스 ShapeNet 수준에서만 검증되었다. 또 occupancy만 다루므로 색·재질은 생성하지 않는다.
