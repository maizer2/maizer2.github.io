# Frido: Feature Pyramid Diffusion for Complex Scene Image Synthesis

* 저자 : Wan-Cyuan Fan, Yen-Chun Chen, Dongdong Chen, Yu Cheng, Lu Yuan, Yu-Chiang Frank Wang (NTU, Microsoft)
* 학회 : AAAI 2023, [arXiv:2208.13753](https://arxiv.org/abs/2208.13753)
* 코드 : [https://github.com/davidhalladay/Frido](https://github.com/davidhalladay/Frido)

## 한 줄 요약

Latent diffusion이 단일 해상도의 잠재 공간에서 모든 것을 한꺼번에 복원하는 것과 달리, Frido는 이미지를 **여러 scale의 양자화된 잠재 특징(feature pyramid)**으로 분해하고, **coarse scale부터 fine scale 순서로 denoising**한다. 이렇게 하면 복잡한 장면에서 전체 구조(물체 배치)와 세부(물체 외형)를 나눠 학습할 수 있어, text / layout / scene graph / label 조건의 여러 벤치마크에서 FID를 개선했다.

## Abstract

기존의 Diffusion 모델들은 high-quality image synthesis에서 높은 성능을 보여주었다.

하지만 이미지에 크기가 다른 객체가 여러 개 포함될 때, 쉽게 말해 복잡한 장면(complex scene)에서는, 전역 구조와 객체 세부를 동시에 잡아야 하기 때문에 객체를 정확하게 생성하지 못한다.

본 논문에서는 이를 해결하기 위해 U-Net 모델에 Feature Pyramid<sup>[FPN](https://maizer2.github.io/1.%20computer%20engineering/2023/06/12/FPN.html)</sup> 구조를 추가하여 coarse-to-fine feature를 학습하는 **Frido (Feature Pyramid Diffusion)** 를 제안한다.

## 1. Introduction

* Latent Diffusion(LDM)은 VQGAN 잠재 공간에서 확산을 수행해 효율을 높였지만, 잠재 특징이 단일 scale이라 "어디에 무엇이 있는가"(구조)와 "그것이 어떻게 생겼는가"(세부)가 섞여서 학습된다.
* 복잡한 장면은 객체 수가 많고 크기 차이가 크므로, 사람도 그림을 그릴 때 하듯이 **큰 구조를 먼저 정하고 세부를 나중에 채우는** 순서가 자연스럽다.
* Frido는 이 직관을 (1) 다중 scale 양자화 오토인코더, (2) scale 순서대로 진행되는 확산 과정, (3) feature pyramid U-Net 세 요소로 구현한다.

## 3. Method

### 3.1 Multi-Scale VQGAN (MS-VQGAN)

* 이미지 $x$를 인코딩해 $N$개 scale의 잠재 특징 $\{z^1, \dots, z^N\}$을 만든다. $z^1$이 가장 coarse(저해상도), $z^N$이 가장 fine(고해상도)이다.
* 각 scale은 자신의 codebook으로 **벡터 양자화**된다. Coarse scale은 색·배치 같은 전역 정보를, fine scale은 질감과 경계 같은 세부 정보를 담도록 구조상 분리된다.
* 디코더는 모든 scale의 특징을 모아 이미지를 복원한다. 단일 scale VQGAN보다 재구성 품질이 좋다.

### 3.2 Feature Pyramid Diffusion

* 확산을 scale별로 **순차적**으로 정의한다. Forward process는 fine scale $z^N$부터 노이즈를 더해 가고, reverse process는 **coarse scale $z^1$을 먼저 복원한 뒤 다음 scale로 넘어간다**.
* 즉 전체 time step을 scale 수만큼 구간으로 나누어, 구간 $s$에서는 scale $s$의 특징만 denoising하고 이미 복원된 coarse scale 특징은 조건으로 사용한다.
* 이렇게 하면 모델은 "이미 정해진 배치 위에 세부를 채우는" 문제만 풀면 되므로 복잡한 장면에서 객체가 뭉개지거나 사라지는 현상이 줄어든다.

### 3.3 Feature Pyramid U-Net (PyU-Net)

* Scale마다 다른 해상도의 특징을 하나의 U-Net이 처리하도록, 입력 측에 scale별 lightweight 인코더를 두고 출력 측에 scale별 디코더를 둔다.
* **Coarse-to-fine gating** : 현재 scale을 denoising할 때 이미 복원된 coarse 특징을 gating 모듈을 통해 주입한다. Coarse 정보가 "힌트" 역할을 하면서도 fine 특징 학습을 방해하지 않도록 조절한다.
* 조건(텍스트, layout, scene graph, label)은 LDM과 같이 cross-attention으로 넣는다. 텍스트는 CLIP 텍스트 인코더, layout과 scene graph는 각각의 임베딩 네트워크로 토큰화한다.

## 4. Experiments

### 과제와 데이터셋

| 과제 | 데이터셋 |
| --- | --- |
| Text-to-image | COCO |
| Layout-to-image | COCO, OpenImages |
| Scene-graph-to-image | COCO, Visual Genome |
| Label-to-image | COCO |

### 결과

* 다섯 벤치마크 모두에서 **당시 최고 수준의 FID**를 보고한다. 특히 layout-to-image와 scene-graph-to-image처럼 객체 배치가 중요한 과제에서 LDM 계열 대비 개선 폭이 크다.
* 정성 결과에서, 단일 scale LDM이 객체를 누락하거나 겹쳐 그리는 장면에서 Frido는 객체 수와 위치를 더 잘 지킨다.
* **Ablation**
    * Scale 수를 1(=LDM)에서 2로 늘리면 FID가 뚜렷이 좋아진다.
    * Coarse-to-fine 순서를 없애고 모든 scale을 동시에 denoising하면 이득이 줄어든다.
    * Gating을 제거하면 fine scale 학습이 coarse 정보에 과도하게 의존해 세부 품질이 떨어진다.

## 5. 정리 및 의의

* **기여** : "확산을 어떤 순서로 할 것인가"라는 축을 추가했다. 픽셀 또는 단일 잠재 공간에서 전 영역을 동시에 denoising하는 대신, FPN처럼 **의미 수준이 다른 scale을 순차 복원**하는 설계가 복잡한 장면에서 유리함을 보였다.
* **연결** : [FPN](https://maizer2.github.io/1.%20computer%20engineering/2023/06/12/FPN.html)의 "coarse feature의 의미 정보를 fine feature에 전달한다"는 아이디어를 생성 모델의 확산 순서로 옮긴 것으로 볼 수 있다. 이후 cascaded diffusion, multi-resolution 잠재 확산 연구와 같은 방향에 있다.
* **한계** : scale 수만큼 확산 구간이 늘어나 샘플링 비용이 증가하고, MS-VQGAN을 별도로 학습해야 한다. 또 scale 분할이 2~3단계로 고정되어 장면 복잡도에 적응하지 못한다.
