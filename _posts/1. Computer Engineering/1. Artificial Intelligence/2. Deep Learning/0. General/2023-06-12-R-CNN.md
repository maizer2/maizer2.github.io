# Rich feature hierarchies for accurate object detection and semantic segmentation

* 저자 : Ross Girshick, Jeff Donahue, Trevor Darrell, Jitendra Malik (UC Berkeley)
* 학회 : CVPR 2014, [arXiv:1311.2524](https://arxiv.org/abs/1311.2524)

## 한 줄 요약

"영역을 먼저 뽑고(region proposal), 각 영역을 CNN으로 분류한다"는 R-CNN 구조를 제안해 PASCAL VOC 검출 성능을 한 번에 30% 이상 끌어올렸다. 또한 **대규모 분류 데이터로 사전학습한 CNN을 소규모 검출 데이터로 fine-tuning**하는 것이 효과적임을 처음으로 보여, 이후 "사전학습 → 미세조정" 패러다임의 출발점이 되었다.

## Abstract

Region proposals과 CNN을 결합하여 object detection network인 R-CNN을 제안한다.

* VOC 2012에서 mAP 53.3%로 이전 최고 결과 대비 30% 이상의 상대적 향상을 달성했다.
* 라벨된 데이터가 부족할 때 **보조 과제(ImageNet 분류)로 지도 사전학습 후 도메인별 fine-tuning**을 하면 성능이 크게 오른다는 것을 보였다.

## 1. Introduction

Object detection은 영상 내부의 모든 객체를 localization해야 한다.

CNN을 검출에 쓰는 가장 단순한 방법인 sliding window 방식은 두 가지 문제가 있다고 언급한다.
* 첫 번째 **Receptive Field 문제**, CNN 네트워크의 상위 layer는 receptive field가 매우 커서(AlexNet 기준 195×195) 정확한 위치 결정이 어렵다.
* 두 번째 **Stride 크기 문제**, 상위 layer의 stride가 커서(32픽셀) sliding window로 위치를 세밀하게 잡기 어렵다.

본 논문은 **recognition using regions** 패러다임을 object detection과 semantic segmentation에 적용하여 높은 성능을 보여주었다. 두 번째 문제인 "검출용 라벨 데이터 부족"은 ImageNet 사전학습 + fine-tuning으로 해결한다.

## 2. Object detection with R-CNN

R-CNN은 세 가지 모듈로 구성된다.

1. 영상 내부 object의 예측 영역을 생성한다. (최대 2,000개)
2. 예측된 영역을 CNN을 사용하여 특징을 추출한다.
3. SVMs을 사용하여 예측된 영역의 객체를 추정한다.

### 2.1 Module design

* **Region proposals** : 방법에 구애받지 않지만 실험에서는 **Selective Search**를 써서 이미지당 약 2,000개의 후보 영역을 만든다.
* **Feature extraction** : 각 영역을 CNN(AlexNet, 5 conv + 2 fc)에 넣어 4096차원 특징을 뽑는다. CNN 입력 크기가 227×227로 고정이므로 영역의 종횡비를 무시하고 **warp**한다. warp 전에 주변 16픽셀의 context를 포함시키면 성능이 조금 오른다.

### 2.2 Test-time detection

1. Selective Search로 약 2,000개 영역 추출
2. 각 영역을 warp → CNN forward → 4096-d 특징
3. 클래스별 선형 SVM으로 점수 계산
4. 클래스별로 **greedy non-maximum suppression(NMS)** 적용. IoU가 임계값 이상인 낮은 점수 영역을 제거한다.

* 효율성 : 모든 클래스가 CNN 파라미터를 공유하고 특징 차원이 낮아, SVM 계산은 행렬 곱 한 번으로 끝난다. 그래도 CNN forward를 2,000번 해야 해서 GPU로 이미지당 약 13초, CPU로 약 53초가 걸린다.

### 2.3 Training

* **Supervised pre-training** : ILSVRC 2012 분류 데이터(이미지 수준 라벨만 있음)로 CNN을 사전학습한다.
* **Domain-specific fine-tuning** : 마지막 1000-way 분류층을 (N+1)-way(N 클래스 + 배경)로 바꾸고, warp된 proposal로 SGD 학습을 계속한다. Ground truth와 IoU ≥ 0.5인 proposal을 positive, 나머지를 negative로 둔다. 학습률은 사전학습의 1/10(0.001). 미니배치 128개 중 32개를 positive, 96개를 background로 구성한다.
* **Object category classifiers** : 클래스별 선형 SVM을 학습한다. 여기서는 IoU < 0.3인 영역을 negative, ground truth만 positive로 두며(fine-tuning과 기준이 다르다), hard negative mining을 쓴다. SVM을 따로 두는 이유는 softmax 출력을 그대로 쓰면 VOC 2007 mAP가 54.2%에서 50.9%로 떨어졌기 때문이다.

### 2.4 Results on PASCAL VOC 2010-12

* VOC 2010 test에서 mAP **53.7%**, 같은 region proposal을 쓰는 UVA 시스템(35.1%)과 DPM 계열을 크게 앞선다.
* VOC 2012 test에서 mAP **53.3%**.

### 2.5 Results on ILSVRC2013 detection

* 200 클래스 ILSVRC2013 검출에서 mAP **31.4%**로, 2위 OverFeat(24.3%)를 크게 앞선다.

## 3. Visualization, ablation, and modes of error

* **특징 시각화** : pool5 유닛별로 가장 높게 활성화되는 영역을 보여 주면 사람, 글자, 개 얼굴 등 의미 있는 패턴을 학습했음을 볼 수 있다.
* **Ablation (fine-tuning 없이)** : pool5, fc6, fc7 특징의 성능 차이가 작다. CNN 표현력의 대부분이 conv layer에서 나오며, fc layer는 파라미터의 대부분을 차지하지만 기여는 작다.
* **Ablation (fine-tuning 후)** : fc6, fc7이 크게 좋아져 mAP가 약 8 포인트 상승(54.2%). 사전학습된 pool5 특징이 범용적이고, fine-tuning은 그 위의 domain-specific 분류기를 학습하는 효과라고 해석한다.
* **네트워크 구조** : AlexNet 대신 VGG-16(OxfordNet)을 쓰면 VOC 2007 mAP가 58.5%에서 **66.0%**로 오른다. 대신 7배 느리다.
* **Bounding-box regression** : pool5 특징으로 박스 위치를 보정하는 선형 회귀를 추가하면 mAP가 3~4 포인트 오른다 (VOC 2007 기준 54.2% → 58.5%). 오류 분석에서 가장 큰 오류 원인이 localization이었기 때문이다.

## 4. Semantic segmentation

* 같은 틀을 segmentation에 적용한다. CPMC로 영역을 뽑고, 영역을 CNN에 넣는 방법으로 **full**(영역 포함 박스 전체), **fg**(배경을 평균값으로 채운 전경만), **full+fg** 세 가지를 비교한다. full+fg가 가장 좋다.
* VOC 2011 test에서 평균 segmentation accuracy **47.9%**로 당시 최고인 O2P를 넘었다.

## 5. 정리 및 한계

* **기여** : (1) region proposal + CNN이라는 검출 패러다임, (2) 사전학습 + fine-tuning의 유효성 입증, (3) bbox regression, hard negative mining 등 이후 표준이 되는 요소들.
* **한계**
    * 학습이 3단계(fine-tuning, SVM, bbox regression)로 나뉘어 번거롭고, 특징을 디스크에 저장해야 한다.
    * 영역마다 CNN을 다시 돌려 매우 느리다.
    * warp가 물체를 왜곡한다.
* 이 한계들은 SPPNet(공유 feature map에서 pooling), Fast R-CNN(RoI pooling + end-to-end 학습), Faster R-CNN(RPN으로 proposal도 학습), 그리고 [FPN](https://maizer2.github.io/1.%20computer%20engineering/2023/06/12/FPN.html)(다중 scale feature)으로 차례로 해결된다.
