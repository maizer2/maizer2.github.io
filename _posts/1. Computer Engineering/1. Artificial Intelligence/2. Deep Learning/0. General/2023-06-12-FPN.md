# Feature Pyramid Networks for Object Detection

* 저자 : Tsung-Yi Lin, Piotr Dollár, Ross Girshick, Kaiming He, Bharath Hariharan, Serge Belongie (FAIR, Cornell)
* 학회 : CVPR 2017, [arXiv:1612.03144](https://arxiv.org/abs/1612.03144)

## 한 줄 요약

CNN의 각 stage가 만드는 feature map들을 **top-down 경로와 lateral connection으로 연결**해, 모든 해상도에서 의미 정보가 풍부한 feature pyramid를 추가 비용 거의 없이 만드는 방법을 제안한다. Faster R-CNN에 붙이면 특히 작은 물체 검출이 크게 좋아지고 COCO에서 당시 single-model 최고 성능을 냈다.

## Abstract

Feature pyramids는 다양한 scale의 objects를 감지하는 방법론이다.

본 논문은 CNN을 적용하여 multi-scale pyramid 구조인, Feature Pyramid Network (FPN)을 보여준다.

기존의 Faster R-CNN에 FPN을 적용하여 높은 성능을 보여주었다.

## 1. Introduction

Object를 다양한 scale에서 인식하는 것은 이미지에 존재하는 다양한 크기의 object를 이해하는데 필수적이다.

특히 작은 object를 인식하는데는 필수적이다.

피라미드를 만드는 기존 방식과 그 문제점은 다음과 같다.

* **(a) Featurized image pyramid** : 이미지를 여러 크기로 resize해서 각각 feature를 뽑는다. 정확하지만 추론 시간이 scale 수만큼 늘어나고, 학습 시에는 메모리 때문에 쓰기 어렵다.
* **(b) Single feature map** : 마지막 layer의 feature 하나만 쓴다(Faster R-CNN 기본). 빠르지만 작은 물체 정보가 다운샘플링으로 사라진다.
* **(c) Pyramidal feature hierarchy** : CNN 중간 layer들을 그대로 쓴다(SSD). 얕은 layer는 해상도는 높지만 의미 정보가 약해 작은 물체 인식에 불리하다.
* **(d) FPN** : (c)처럼 비용은 거의 들지 않으면서, top-down 경로로 깊은 layer의 의미 정보를 얕은 layer까지 내려보내 **모든 level이 강한 의미 정보**를 갖게 한다.

## 3. Feature Pyramid Networks

<center>Feature Pyramid Network<sup>[출처](https://herbwood.tistory.com/18)</sup></center>

* **Bottom-up pathway**
    * 기존의 Conv model의 feed forward 과정에서 stage의 마지막 layer의 feature map을 추출한다.
        * 여기서 stage란, 이미지 크기가 유지되지만 깊은 layer를 쌓기 위해 추가되는 layer들의 묶음이다.
        * Stage의 마지막 layer에서 feature map을 추출하는 이유는, 그 stage의 feature 중 가장 강력한 정보가 담겨 있기 때문이다.
    * ResNet 기준 conv2, conv3, conv4, conv5의 마지막 residual block 출력을 $\{C_2, C_3, C_4, C_5\}$라 하며, 입력 대비 stride는 각각 $\{4, 8, 16, 32\}$이다.
    * 첫 번째 stage(conv1)는 feature map이 너무 커서 메모리 문제 때문에 피라미드에서 제외한다.

* **Top-down pathway and lateral connections**
    * 가장 깊은 $C_5$에서 시작해 **nearest neighbor upsampling으로 공간 크기를 2배** 키운다.
    * 같은 크기의 bottom-up feature $C_i$에 **1×1 conv**를 적용해 채널을 맞춘 뒤 **element-wise 덧셈**으로 합친다 (lateral connection). 1×1 conv는 채널 수를 맞추는 동시에 얕은 layer의 정확한 위치 정보를 가져오는 역할을 한다.
    * 합친 결과에 **3×3 conv**를 한 번 더 적용해 upsampling으로 생긴 aliasing을 줄이고 최종 $\{P_2, P_3, P_4, P_5\}$를 만든다.
    * 모든 $P_i$의 채널 수는 $d = 256$으로 통일한다. 피라미드의 모든 level이 같은 classifier / regressor head를 공유하기 때문이다.
    * 추가적인 비선형성은 넣지 않았는데, 실험적으로 효과가 미미했다고 한다.

## 4. Applications

### 4.1 Feature Pyramid Networks for RPN

* 원래 RPN은 단일 feature map 위에서 3×3 sliding window와 여러 scale·ratio의 anchor를 쓴다.
* FPN에서는 **각 level에 하나의 scale**만 배정한다. $\{P_2, P_3, P_4, P_5, P_6\}$에 각각 $\{32^2, 64^2, 128^2, 256^2, 512^2\}$ 크기의 anchor를 두고, 종횡비는 $\{1{:}2, 1{:}1, 2{:}1\}$ 세 가지를 쓴다. 총 15종의 anchor가 된다. $P_6$는 $P_5$를 stride 2로 subsampling한 것으로 RPN에서만 쓴다.
* Head(3×3 conv + 두 개의 1×1 conv)의 파라미터는 **모든 level에서 공유**한다. 공유하지 않아도 성능 차이가 없어, 피라미드의 모든 level이 비슷한 의미 수준을 가진다는 증거로 해석한다.

### 4.2 Feature Pyramid Networks for Fast R-CNN

* RoI를 크기에 따라 어느 level $P_k$에서 pooling할지 정한다. RoI의 폭·높이를 $w, h$라 하면

$$ k = \left\lfloor k_0 + \log_2\big(\sqrt{wh}/224\big) \right\rfloor, \qquad k_0 = 4 $$

* 224는 ImageNet 사전학습 크기이며, 224² 크기의 RoI는 $P_4$에 배정되고 그보다 작으면 더 높은 해상도의 level로 간다.
* 모든 level에 **같은 head**(두 개의 1024-d fc layer → cls / bbox)를 붙인다.

## 5. Experiments on Object Detection (COCO)

* **RPN (proposal quality, AR)** : ResNet-50 기준 baseline 대비 $AR^{1k}$가 약 8 포인트 상승하며, 특히 작은 물체의 $AR_s$가 크게 오른다.
    * Ablation : top-down 경로를 빼거나, lateral connection을 빼거나, $P_2$만 단일로 쓰면 모두 성능이 떨어진다. 세 요소가 모두 필요하다.
* **Fast / Faster R-CNN (AP)** : ResNet-101 Faster R-CNN + FPN은 COCO test-dev에서 **AP 36.2**로, 당시 COCO 2016 우승 모델을 포함한 single-model 결과를 넘어섰다. 이미지 피라미드나 반복 regression 같은 트릭 없이 얻은 수치다.
* **속도** : 단일 scale 추론으로 이미지당 약 0.15초(ResNet-50, M40 GPU). Featurized image pyramid보다 훨씬 빠르다.

## 6. Extensions: Segmentation Proposals

* DeepMask / SharpMask 스타일의 segment proposal에도 FPN을 적용해, 각 level에서 5×5 window로 mask를 예측하게 하면 기존 방법보다 AR이 높고 속도도 빠르다. 이후 Mask R-CNN의 기본 backbone이 되었다.

## 정리

* **기여** : 깊은 layer의 의미 정보를 top-down으로 전달해 모든 해상도의 feature를 강하게 만드는, 범용적이고 가벼운 backbone 구조.
* **의의** : 이후 Mask R-CNN, RetinaNet, 대부분의 detector와 segmentation 모델이 FPN 또는 그 변형(PANet, BiFPN 등)을 쓴다. Diffusion 모델에서도 [Frido](https://maizer2.github.io/1.%20computer%20engineering/2023/06/12/Frido.html)처럼 coarse-to-fine feature를 쓰기 위해 같은 아이디어를 빌려온다.
* **한계** : 가장 높은 해상도 $P_2$를 쓰므로 메모리 사용량이 크고, level 배정 규칙이 휴리스틱이다.
